# Student Registration & Results Manager

## Purpose
Register students, enter marks for three subjects, and produce individual reports and class summaries.

## Features
- Register students with unique admission numbers.
- Validate marks from 0 to 100.
- Calculate totals, averages, grades and pass/fail results.
- Search students and identify top performers.

## Requirements
- Python 3.10 or later
- No third-party packages required

## How to run
1. Open a terminal in this project folder.
2. Run `python main.py`.
3. Follow the on-screen menu.
